# Intel Sustainability Journey

This project is a beginner-friendly website that shows important milestones in Intel's sustainability and innovation story.

The page uses a timeline-style layout with cards for different years. Each card includes a title, image, and short description. Users can scroll through the timeline and hover over cards to reveal more details.

## What The Project Does

- Displays Intel milestones from 1968 to 2024 in a visual timeline.
- Highlights sustainability-related progress, including emissions goals and renewable electricity use.
- Provides a responsive design so the page works on desktop and mobile screens.
- Adds simple interactivity with hover effects and keyboard arrow navigation.

## Technologies Used

- HTML5: Builds the structure of the page, including hero content and timeline cards.
- CSS3: Styles the layout, colors, spacing, hover effects, transitions, and mobile behavior.
- JavaScript (vanilla): Adds keyboard-based horizontal scrolling and timeline interaction.
- Image assets: Timeline illustrations and Intel branding located in the `img/` folder.

## Project Files

- `index.html`: Main webpage structure and JavaScript behavior.
- `style.css`: All visual styling and responsive rules.
- `img/`: Logo and milestone images used in the timeline.

## How To Run

1. Open this folder in VS Code or GitHub Codespaces.
2. Open `index.html` in your browser.
3. Explore the timeline by scrolling or using left/right arrow keys when focused.
